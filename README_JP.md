# N64 → N64 L字中継アダプタ v1.1

既存の「N64→Aleck64 変換アダプタ」の N64 スロットに挿して、**N64 カートを縦向き（アダプタ基板と平行）に立てる**ための中継基板です。

```
  [N64カート]  ← 縦に立つ。ラベルは手前（アダプタ基板と反対）向き
      │
 ┌────┴────┐  ← この基板（水平）
 │  L字中継 │
 └──┬──────┘
    │ カードエッジ
 ┌──┴───────┐
 │ N64→Aleck64 アダプタ（垂直）│
 └──────────┘
```

## 基板
- 外形 84 × 52 mm、**厚み 1.2 mm**、2層
- 下端が N64 カードエッジ（2.5 mm ピッチ、25×2、金フィンガー）
- 上側に N64 カートスロット（2.5 mm ピッチ 50ピン）を実装
- 配線は 50 ピンすべて 1:1 のストレート

## PCBWay 発注設定
| 項目 | 設定 |
|---|---|
| アップロード | `N64_to_N64_L_riser_v1_gerber.zip` |
| 層数 | 2 |
| **板厚** | **1.2 mm** |
| **Gold fingers** | **Yes** ＋ **Beveling / 面取り 45°** |
| 表面処理 | ENIG 推奨 |
| 最小配線/間隔 | 0.2 / 0.2 mm、最小穴 0.3 mm |

## 部品
- **N64 用 50ピン カートリッジスロット** 1個（本体補修用として売られている 2.5 mm ピッチの部品。例：eBay / AliExpress / Hexir などで「N64 50 pin cartridge slot connector」）
- 穴は φ0.9 mm（元アダプタの φ0.85 より少し大きめ。入りにくい場合に備えています）

## 組み立てと使い方
1. スロットは、**「SOLDER THE N64 CART SLOT ON THIS SIDE / THIS SIDE FACES UP」と書いてある面（B面＝使うとき上を向く面）**に本体を載せ、ピンは反対のF面でハンダ付けします。四角いパッドが1番ピンです。
   - この面は、下端のカードエッジの「1〜25番ピン側」と同じ面です。F面側に付けると、カートが下向き（アダプタ基板の方）に生えてしまい入りません。
   - なお、コネクタ部品自体には向き（極性）がないので、挿す面さえ合っていれば配線は正しくつながります。
2. この基板を、N64→Aleck64 アダプタの N64 スロットに挿します。**裏面（B面）のシルク「THIS SIDE UP」が上**になる向きです。逆向きに挿すと配線が入れ替わるので、必ず確認してください（カードエッジにはキーがありません）。
3. N64 カートは、ラベルが**カードエッジと反対側**（シルクの矢印「CART LABEL FACES THIS WAY」の向き）を向くように、上から挿します。

## 注意
- この基板は、元アダプタのスロットに片持ちで刺さります。カートを立てると重心が上がるので、支え（スペーサーや固定具）を用意すると安心です。上側の φ3.2 穴2か所が使えます。
- カートが立つ分、上方向に 10 cm 強の空間が必要です。
- 未検証の新規設計です。まず1枚試作して、スロットに挿さるか・カートが認識されるか確認してください。

## 検証
- KiCad DRC：エラー0 / 未配線0
- 出力 Gerber を画像化して導通を独立に再チェック：50ピン（33ネット）すべて 1:1 で一致（PASS）
  - 左右を入れ替えた対応表で照合すると FAIL になることも確認（向きが効いていることの裏取り）
